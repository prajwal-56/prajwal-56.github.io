## How someone can even make a custom linux distro
It's basically reverse engineering an exisiting linux distro (often called base distro) - and then you **[customize](/blogs/wdymby%20customizing.md) it** and then package it into an iso file that people can download.

So, you pick a base distro -> rice it -> package it into an iso.

#### But how do you actually do the ricing and package into an iso
People do this often. There are dedicated tools which makes the job 10x easier. 
- If you chose the base distro to be <mark style="background-color:orange;font-weight:bold; padding:0px 3px 0px 3px; border-radius:16px;">Ubuntu</mark> - there's CUBIC (Custom Ubuntu ISO Creator)
- If you chose the base distro to be <mark style="background-color:black;color:red;font-weight:bold; padding:0px 3px 0px 3px; border-radius:16px;">Debian</mark> - there's `live-build`, CUBIC works on debian too or you can literally do what CUBIC and others do under the hood - **chroot**
- If <mark style="background-color:black; color:cyan;font-weight:bold; padding:0px 3px 0px 3px; border-radius:16px;">Arch</mark> - there's `archiso` and calamares - but the process would be different than CUBIC tho


## How Accessible Coconut 22.04 is built 
AC 22.04 - I believe this is the first ever version of AC.
It was built on top of Ubuntu 22.04. 
Basically, changed the desktop environment to *MATE*, installed some apps, customize the panels, added a few things to make the UX better and then finally, rebranded (i.e. , changed the wallpaper and everything).
That's pretty much it i guess.
